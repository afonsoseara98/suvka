# Project

Name: Noctra

Purpose:

Build the world's most intelligent AI platform for generating high-converting landing pages.

The product is not an AI website builder.

The product is an AI Conversion System.

# High-Level Architecture

```
User Prompt
        │
        ▼
AI Engine
        │
        ▼
Structured Landing JSON
        │
        ▼
React Renderer
        │
        ▼
Landing Page
```

React is responsible only for rendering.

All business intelligence lives inside the AI Engine.

# Module Responsibilities

## Business Intelligence

Understands:

- Industry
- Business Model
- Audience
- Goal
- Positioning
- Pricing
- Tone

---

## Psychology Engine

Determines:

- Pain points
- Desires
- Objections
- Trust factors
- Emotional triggers

---

## Knowledge Engine

Provides structured industry knowledge.

No business-specific knowledge should be hardcoded.

---

## Conversion Engine

Plans:

- Offer
- CTA strategy
- Guarantees
- Social proof
- Urgency
- Section order

---

## Copy Engine

Produces copy only.

It does not make strategic decisions.

---

## Design Engine

Creates:

- Layout
- Colors
- Typography
- Visual hierarchy
- Component styling

---

## Component Engine

Chooses React components based on business context.

---

## Rendering Engine

Transforms Landing JSON into React.

Rendering must remain deterministic.

---

## Validation Engine

Checks:

- Accessibility
- Structure
- Copy consistency
- Missing sections
- Quality

---

# Development Rules

- TypeScript everywhere.
- No duplicated logic.
- No business logic inside React.
- Prefer composition over inheritance.
- Prefer configuration over hardcoded logic.
- Every module must have one responsibility.
- Every module must expose typed inputs and outputs.
- AI reasons using structured objects.
